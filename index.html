สรุป Subnetting & IP Allocation Lab

ระบบสุ่มโจทย์แบบ Multi-Subnet (1-4 Subnet) พร้อมอธิบายหลักการหา Host อย่างละเอียดเพื่อเตรียมพิชิตข้อสอบ

1. ทริค สูตร เทคนิค และ Keywords ที่ต้องจำก่อนสอบ

ท่องจำกฎเหล็กช่วยให้ทำข้อสอบคำนวณและ Lab ได้รวดเร็ว

สูตรที่ 1: จำนวน Host

Usable Hosts

2h - 2

โดย h = จำนวนบิต Host (ศูนย์) ต้องลบ 2 เสมอสำหรับ Network IP และ Broadcast IP

สูตรที่ 2: Block Size

Magic Number

256 - Subnet Mask Octet

ใช้นับช่วงย่าน Network IP ถัดไปได้อย่างรวดเร็ว เช่น 0, 64, 128, 192

สูตรที่ 3: ความสัมพันธ์บิต

Network + Host = 32

h = 32 - Prefix

เช่น /27 จะเหลือ Host bits = 32 - 27 = 5 บิต คิดเป็น Usable Hosts = 2⁵ - 2 = 30

3. หลักการหาจำนวน Host อย่างละเอียด

วิธีการคำนวณบิตโฮสต์และการเลือกใช้ Prefix ให้สอดคล้องกับความต้องการของโจทย์

กฎการคำนวณหา Usable Hosts

เมื่อโจทย์กำหนดว่าต้องการรองรับเครื่องโฮสต์ (คอมพิวเตอร์, เซิร์ฟเวอร์, พอร์ตเราเตอร์) จำนวน X เครื่อง เราจะต้องหาค่าจำนวนบิตโฮสต์ (h) ที่น้อยที่สุดที่ทำให้สมการนี้เป็นจริง:

2h - 2 ≥ X

*เหตุผลที่ต้อง **- 2** เพราะในแต่ละ Subnet จะต้องถูกหักออก 2 IP เสมอคือ:*
1. **Network IP:** ไอพีแรกสุด (ใช้ระบุตัวตนเครือข่าย ห้ามกำหนดให้เครื่อง Host)
2. **Broadcast IP:** ไอพีสุดท้าย (ใช้ส่งข้อมูลหาทุกเครื่องในวง ห้ามกำหนดให้เครื่อง Host)

ตัวอย่างการเลือก Prefix จากจำนวน Host

  • • ต้องการ 50 Hosts -> ลอง h=5 (2^5-2 = 30 ไม่พอ) -> ใช้ h=6 (2^6-2 = 62 พอดี) -> ได้ Prefix = 32-6 = /26
  • • ต้องการ 20 Hosts -> ลอง h=4 (2^4-2 = 14 ไม่พอ) -> ใช้ h=5 (2^5-2 = 30 พอดี) -> ได้ Prefix = 32-5 = /27
  • • ต้องการ 2 Hosts (WAN Link) -> ใช้ h=2 (2^2-2 = 2 พอดีเป๊ะ) -> ได้ Prefix = 32-2 = /30
